# Pedidos — General Distribution

App para levantar pedidos en tienda. Un solo archivo, sin base de datos y sin cuentas.

- 551 productos con foto, precio y categoría (catálogo del 28 de septiembre de 2026).
- Buscador y filtros: Dulces, Abarrotes, Bebidas, Botanas.
- El pedido se guarda solo en el teléfono y se manda por WhatsApp.

Se abre aquí: https://generaldistributionmx-del.github.io/pedidos-gd/
